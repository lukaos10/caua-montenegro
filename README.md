# Cauã Montenegro

Site de apresentação do videomaker Cauã Montenegro. O desenho segue a estrutura de [Rodrigues Filmmaker](https://rodriguesfilmm.com.br/): abertura, portfólio em espaços, sobre, serviços e briefing.

Instagram: [@cauamontenegroo](https://instagram.com/cauamontenegroo)  
Orçamentos: [linktr.ee/cauamontenegroo](https://linktr.ee/cauamontenegroo)

As fotos da página são imagens de exemplo (Unsplash). Os trabalhos reais ficam no Instagram.

## Rodar localmente

```bash
npm install
npm run dev
```

## WhatsApp

O formulário copia o briefing. Sem número, ele abre o Linktree. Para abrir o WhatsApp direto, preencha `WHATSAPP_E164` em `src/portfolio.ts` só com dígitos, incluindo DDI. Exemplo: `5585999999999`.

## Trocar as fotos

Edite a lista `spaces` em `src/portfolio.ts`.
